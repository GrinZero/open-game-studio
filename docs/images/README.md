# README image provenance

[English README](../../README.md) · [Original sample notices](../../licenses/THIRD_PARTY.md)

- `badges.svg` is original local SVG artwork for the status and requirements strip. It avoids dependence on a remote badge service.
- `open-in-colab.svg` is original local SVG badge artwork for the Monster Colab notebook launcher, avoiding external badge image requests.
- `banner.svg` is original vector artwork created for Open Game Studio. Its connected cards illustrate references, a brief, a pinned asset and delivery; it is a conceptual illustration, not a product screenshot.
- `projects.png` and `canvas.png` are actual Chromium captures of the production HTTP build on 2026-10-12 (Asia/Taipei), at 1440 × 960, from an isolated temporary registry and demo project. They show the build marker `v0.1.7-20261012020714`.
- The demo was created by `scripts/demo.ts`, using the repository's original `samples/reference.png`, `samples/moodboard.png` and `samples/brief.md`. No user registry, private project assets, model generation, paid task or engine acceptance was involved.
- Screenshots show the current Chinese UI. They have not been retouched or presented as a translated interface. The temporary filesystem path visible in the screenshots belongs to the isolated capture environment.
- The gallery is historical documentation, not evidence that the user's current workbench refreshed or that a model passed production validation.
