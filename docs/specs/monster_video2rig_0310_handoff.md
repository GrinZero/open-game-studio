## 修改

多足路径改在实体体素的26邻接图中运行Dijkstra，边代价为`norm(offset) * (1 + 3 / (0.5 * (depth_a + depth_b) + 0.5))`。深度以体素计；统一乘上物理体素尺寸不改变最短路径。原实现仅在细化骨架上寻路，无法在实体内部自由选择较宽的通道。

共享躯干段先按路径归属裁去，再用厚躯干核心及其扩张范围排除拥挤的肢根区域；没有独立厚躯干的等宽分叉形态保留原共享分叉切分。每条路径的同一体素只计一次，避免密集采样把单条路径误算成多个共享分支。

三个中间关节分别在22%/50%/78%弧长附近寻找显著弯曲，不再把全路径最强的三个相邻尖峰当成三个关节。左右对应腿使用两侧实测比例的均值，并在各自完整路径上按相同比例插值。

左右腿按躯干出发点前后次序与镜像距离匹配，允许缺失对应侧，保留全部未配对腿。4左/2右的形态不再被`zip`截成4条腿，后端真配对也不会因中间缺腿而错配。单体素触地点及细腿可进入多足判别；普通缺腿移植入口仍保留原薄下摆过滤。少于6条触地腿或空体积不启用多足替换。

生产候选中的Coxa挂到最近的实际躯干骨段，保留完整腿链父关系；不再全部挂到组织Root。
