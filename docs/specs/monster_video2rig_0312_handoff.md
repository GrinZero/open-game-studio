# Monster 0.3.12：层级变换、四向局部轴与 Heat 边界验收

本批推进原Plan P1前置清洗与P2局部轴/外壳蒙皮，保留0.3.11全部修复。原Plan其他未验收项继续实施。

输入GLB的轴向、单位缩放和位置可能保存在父Empty。此前删除父节点再应用网格变换会丢失继承变换；双层父节点、1.25倍缩放的反例中，角色应为2.5高却变成2.0，几何最大偏差约0.508。现在先缓存每个网格的世界矩阵，解除父链、删除非网格节点后恢复矩阵再合并。

另一个实际缺陷是GLTF导入对象保留QUATERNION旋转模式，给rotation_euler赋值不会生效，导致报告声称转向但网格方向未变。应用朝向前显式切到XYZ。修复后四个来源朝向0/90/180/270均回到同一规范网格，最大几何误差2.41e-7。

原生四场景各含两层父节点、非零对象变换、八根骨、故意不同roll和非零Root/Arm/Head起始姿态。实际候选准备、语义交接、蒙皮抽取与FK读回均验证：+Y沿骨，+X采用左向在骨垂面的投影；骨向平行左向时两者无法同时对齐，因此确定性使用+Z投影作X，保持右手正交框架。Blender float32最大正交误差3.22e-6（门限1e-5），框架最大差1.81e-6，表面最大变化5.24e-7。

Heat政策测试在真实100顶点角色上仅对第一次输入Heat结果做故障注入，精确供应49/50/51个获权顶点；实际外壳Heat不替换。49%触发外壳，50%和51%不触发；输入Heat抛错可进入实际外壳，外壳失败则报错并清理。非零起始姿态、对象世界矩阵、pose_position、单个Armature修改器及独立Prop的use_deform标记均恢复。此项证明严格边界，不能称为自然网格恰好得到49%权重。

另一个场景完全运行真实外壳Bone Heat和KD回传：内外两壳的48顶点分裂为12个独立面组件，另有八顶点碎片及独立Prop。100格最长边外壳生成16,068顶点，角色/碎片权重归一化、最多四影响且无Prop串权，Prop保持自身权重；恢复非零起始姿态后表面最大误差2.47e-7，临时对象与数据清理通过。实际.blend与JSON留在native-axes/native-heat。
