# 同坐标逐帧叠图评分

将同一动作、同一帧、同一相机视角的参考与渲染放在原始像素坐标下比较。技能自带 Python CLI，独立于 Blender、MCP 和工作台服务；定位本技能目录后，用其中的相对路径运行，复制整个目录即可移植。

## 执行

1. 核实动作、帧编号、FPS、画布大小及各视角区域。记录相机投影、位置、朝向、尺度与时间对应关系的证据；仅有相同分辨率不足以证明坐标一致。证据不足时保留 `alignment.status: unverified`，仍可生成诊断报告。
2. 使用已有 Python 环境，或在技能目录之外创建环境并安装 `scripts/requirements.txt`。视频先按 [输入说明](references/inputs.md) 无缩放抽帧；已有帧目录可直接使用。执行 `scripts/review.py init --help` 创建 manifest，再根据实际素材检查字段。
3. 执行 `python <技能目录>/scripts/review.py review /absolute/manifest.json --output /absolute/new-review-dir`。默认检查完整序列；调试可加 `--frames 0,24,48-60`。每次使用新输出目录，保留旧报告和素材。
4. 阅读 `report.json` 的覆盖率、缺帧、无效轮廓和相机核实状态，再看每个视角的配对分数与最差帧。打开 `index.html` 可切换帧/视角/区域、调叠图透明度、查看修复前后及差异轮廓。返回至少一张实际生成的叠图及报告链接。

## 判断与后续修复

- 分数均在原分辨率计算；视角与局部 ROI 是各版本共用的固定矩形。工具拒绝尺寸不等的输入，不做平移、缩放、重心对齐或图像变形。展示缩放只影响浏览。
- IoU/Dice 越高越好，边界平均/P95 距离越低越好。修复前后按每个视角、区域的相同有效帧集合统计；缺失或空轮廓明确列出，不补成高分。双视角分开报告，检查其中一个视角的退步。
- 背景阈值分割适合纯背景；检查实际 mask 轮廓。复杂背景、特效或暗色部件需要显式 mask 或透明通道，配置见输入说明。结果描述为 **2D 轮廓匹配**；它不能单独证明三维结构、骨骼、纹理或时序自然度正确。
- 修复时用最差帧和退步视角定位具体身体部位，修改新版本后重跑完全相同的 manifest 条件。只有完整覆盖、坐标核实、全部目标视角和人工检查均满足任务要求时，才能报告验收完成；工具本身不自动判定动作合格。

退出码：`0` 为完整、有效且已声明核实的比较；`2` 为已生成但覆盖不全、坐标未核实或有无效 mask 的诊断报告；`1` 为输入/执行错误。`0` 不代表模型质量通过。
