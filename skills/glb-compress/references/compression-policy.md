# 完整模型压缩：按实际资产评估 v1.2

模型的几何、UV、材质与贴图完成后，默认进入压缩评估。纹理或几何修改后重新评估。保留未压缩源；候选结果不反向替换建模源、训练源或已固定审核版本。

## 默认 KTX2 + 用户对比

默认开启 KTX2（ETC1S / BasisLZ）生成候选，默认保持原贴图尺寸（resizeMax=0）。**生成后必须让用户对比原版与候选，等待用户明确选择后才能采用。** 展示同相机的实际画面与体积差异；用户确认前保留 awaiting_user_comparison、selected=null，不替换正式资产或标记通过。详细步骤与记录格式见 [KTX2 人工对比关卡](ktx2-human-review.md)。

KTX2 是默认试验，不是自动通过的最终编码。实际兼容性、材质效果或节省不合适时，可以增加其他方案供用户比较；缺少编码器或目标无法加载时明确告知，不静默替换为别的编码。

## 处理方式由本次证据决定

不再设置“默认只压颜色图、其他图必须等用户单独提出”的限制；也不把所有 PBR 图统一转 WebP、统一降到 1K/2K。颜色、法线、粗糙度、金属度、AO、自发光等图都可以评估，具体是否调整、采用何种编码和尺寸，由实际体积、材质用途、目标视距与测试结果决定。

1. **查明主要载荷。** 记录每张贴图的字节、尺寸、编码和实际材质槽；区分几何、动画及图像占比。不要根据模型面数或图的名称推断贴图大小。`recommend.mjs` 输出按实际字节排序的 `textureAssessment`，默认给出 KTX2 待审候选，不自动选择交付版本。
2. **针对原因做对照。** 大 PNG 可以先测原尺寸无损重编码；已有紧凑编码或总体节省很少时可直接保留。像素细节过多而实际镜头不需要时，比较降尺寸；有损编码单独测试，不与几何减面混在一次对照中。选择顺序由本次瓶颈决定，并非所有图都必须走完这些试验。
3. **区分文件无损与画面相近。** 无损重编码要比较解码像素与数据解释；缩图和调色板量化不能称为无损。法线、粗糙度等数据的误差会改变受光；合图需核对通道、UV、采样和目标尺寸，不能当作免费优化。
4. **看实际效果再采用。** 固定相机、曝光、光照、视口、过滤方式和动画采样时间，比较原图与候选在正常/最近使用距离的结果；PBR 检查不同光照方向下的凹凸、高光、颜色、自发光细线和透明边缘。选择节省值得且画面达标的版本，没有合适候选时保留原版。

1K/2K/4K、图像占比和三角形区间仅是可能的调查线索，不是强制尺寸、处理范围或统一质量通过线。源图不放大。SSIM/像素误差用于定位同一资产的差异，不提供跨资产自动验收线。

CLI 的 `textures`、`resizeMax`、`mipmaps` 是全图设置，原始编码默认值是执行参数，不是推荐结果。仅在这种统一处理适合当前资产时使用。若各图需要不同编码/尺寸，使用制作工具或单独脚本处理；不能用全图选项冒充单张图处理。

Godot 的 KTX2 运行时加载须先检查 [加载适配说明](godot-ktx2-loading.md)：修正已验证的额外色彩转换，再让用户比较真实压缩效果。默认 KTX2 与人工确认机制保持不变。

## 项目与数据约束

- **Godot 始终关闭 Draco。** CLI 检查输入/当前目录祖先的 `project.godot` 或仓库的 `game/project.godot`，也可传 `--project` / `--engine godot`；显式开启会被拒绝。其他引擎是否使用 Draco，要检查加载器与实际收益。
- 默认保留名称、切线、蒙皮、动画和形态键，不自动焊接或减面。需要几何优化时按实际载荷、轮廓及典型动作独立测试，记录实际达成比例；不因 GLB 大就减面。
- 颜色与数据图分别遵守相应色彩/数据语义；法线缩放需考虑向量过滤和归一化，透明图保留必要 alpha。已有有损误差不能通过无损重编码恢复。
- 文件字节、GPU 显存和帧率分别衡量。Godot VRAM 压缩、KTX2 和 mipmap 通过实际导入/转码链验证，桌面 Forward+ / Mobile 与移动真机结果分开记录。

## 证据与交付

所有试验文件、配置、截图与报告集中在项目允许的专用临时目录，例如 `<临时根>/glb-compression/<资产或批次>/`；不要把候选写入正式资产根或登记为固定审核版本。

记录原/候选字节、贴图尺寸/编码、三角形、蒙皮/动画/形态键数量及扩展，并说明实际观察到的差异、采用或保留原因。Godot 直接加载实际候选；结构读回、截图和真实运行性能分别表述。

压缩候选通过后沿用项目交付/导入流程。KTX2 压缩增加用户视觉对比关卡，必须先等待用户明确选择；角色原有审核关卡继续绑定固定输入。

## SKILL 默认入口

资源制作、角色制作/返修、资产交付及 Monster 工作流，在几何、UV、材质和贴图完成后加载此评估流程。默认步骤是诊断、生成 KTX2 候选和用户视觉选择；候选生成不意味着自动采用。
